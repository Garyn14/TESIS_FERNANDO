## Cobertura del prototipo frente a las historias de usuario

| Épica | Historias | En el prototipo |
|---|---|---|
| E1 Usuarios, roles y áreas | HU01–HU06 | Solo el inicio de sesión (HU03). No incluye el rol Administrador ni el cambio de contraseña (HU04) |
| E2 Registro de solicitudes | HU07–HU09 | HU07 y HU09 (emisión por lista del Certificado de Capacitación). No incluye el formulario a solicitud de parte (HU08) |
| E3 Revisión y autorización | HU10–HU18 | Completa. Firma, IPFS y blockchain simulados |
| E4 Verificación pública | HU19–HU21 | No (proyecto aparte) |
| E5 Consulta y trazabilidad | HU22–HU25 | Completa |
| E6 Notificaciones | HU26–HU28 | Completa |
| E7 Anulación y reemisión | HU29–HU30 | Completa |
